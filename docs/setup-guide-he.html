מסלול א

העברת מיילים אוטומטית (הכי מהיר, בלי הרשאות)

מוסיפים כלל העברה בתיבת המייל, וכל מייל רלוונטי מגיע ל-Sitekick אוטומטית. עובד מ-Gmail ומ-Outlook כאחד.

  1. נשלח לכם כתובת ייעודית (לדוגמה intake@sitekick...) אחרי הקמת הניתוב.
  2. ב-Gmail: הגדרות ← ראה את כל ההגדרות ← Forwarding ← הוספת כתובת העברה ← אישור הקוד שיגיע.
  3. ב-Outlook: Settings ← Mail ← Forwarding ← הזנת הכתובת ← Save.
  4. אפשר גם כלל חכם שמעביר רק מיילים מסוימים (לפי שולח או נושא) במקום הכול.
מה מחזירים אלינו: רק אישור שהכלל הוגדר, ומאיזו תיבה.
מסלול ב

חיבור ישיר ל-Gmail (אם התיבה על Google)

יוצרים הרשאת קריאה-בלבד שמאפשרת ל-Sitekick לסרוק מיילים חדשים אחת ל-10 דקות.

  1. נכנסים ל-console.cloud.google.com עם חשבון התיבה ← יוצרים Project חדש בשם sitekick.
  2. APIs & Services ← Library ← מחפשים Gmail API ← Enable.
  3. APIs & Services ← OAuth consent screen ← External ← מוסיפים את כתובת התיבה כ-Test user.
  4. Credentials ← Create Credentials ← OAuth client ID ← סוג Web application ← ב-Redirect URIs מוסיפים https://developers.google.com/oauthplayground ← שומרים את ה-Client ID ואת ה-Client secret.
  5. נכנסים ל-OAuth Playground ← גלגל השיניים ← מסמנים "Use your own OAuth credentials" ← מדביקים את ה-ID וה-Secret.
  6. בשדה הימני מדביקים את ההרשאה https://www.googleapis.com/auth/gmail.readonly ← Authorize ← מתחברים עם התיבה ← Exchange authorization code for tokens ← מעתיקים את ה-Refresh token.
מה מחזירים אלינו (4 ערכים): Client ID · Client Secret · Refresh Token · כתובת התיבה.
מסלול ג

חיבור Outlook / Microsoft 365 (דרוש אדמין)

רישום אפליקציה בהרשאת קריאת-מייל בלבד. מבצע מי שמנהל את ה-Microsoft 365 של הארגון.

  1. נכנסים ל-entra.microsoft.com ← Identity ← App registrations ← New registration ← שם: sitekick-mail ← Single tenant ← Register.
  2. בעמוד ה-Overview מעתיקים: Directory (tenant) ID ו-Application (client) ID.
  3. Certificates & secrets ← New client secret ← מעתיקים מיד את ה-Value (מוצג פעם אחת).
  4. API permissions ← Add a permission ← Microsoft Graph ← Application permissions ← מסמנים Mail.Read ← Add ← ולוחצים Grant admin consent.
מה מחזירים אלינו (4 ערכים): Tenant ID · Client ID · Client Secret · כתובת התיבה לסריקה.

ההרשאה Mail.Read ברמת אפליקציה חלה כברירת-מחדל על כל התיבות. אפשר (ומומלץ) לצמצם לתיבה אחת בלבד עם Application Access Policy — נשמח להעביר לאדמין את הפקודה המוכנה.

מסלול ד

שיתוף קבצי הגאנט והתקציב (Google Sheets)

Sitekick קורא את הגיליונות ומעדכן לוחות זמנים ותקציב אוטומטית. צריך רק שיתוף לקריאה.

  1. אנחנו נשלח לכם כתובת מיוחדת של "חשבון שירות" (נראית כמו sitekick-sheets@...iam.gserviceaccount.com).
  2. בכל אחד מהקבצים (גאנט + תקציב): Share ← מדביקים את הכתובת ← הרשאת Viewer ← Send.
  3. שולחים לנו את הלינקים לשני הקבצים.
מה מחזירים אלינו: אישור שיתוף + שני הלינקים לקבצים.

אבטחה — בשורה אחת לכל סעיף

· כל ההרשאות הן קריאה בלבד — המערכת לא שולחת, לא מוחקת ולא משנה שום דבר בתיבות או בקבצים.
· כל חיבור ניתן לביטול בלחיצה אחת (הסרת הכלל / מחיקת ה-App / הסרת השיתוף).
· את הערכים הסודיים (Secrets/Tokens) לא שולחים במייל גלוי — עדיף בהודעה חולפת (WhatsApp) או בשיחה, ואנחנו מזינים ומוחקים.
